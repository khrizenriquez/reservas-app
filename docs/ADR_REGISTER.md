# ADR Register

| ADR | Status | Decision |
|---|---|---|
| ADR-011 | Active | Expo/React Native is the native mobile stack. |
| ADR-012 | Active | Spec-driven development is mandatory. |
| ADR-013 | Active | Trunk-based delivery uses focused branches. |
| ADR-016 | Active | Requirement-to-test traceability is required. |
| ADR-018 | Active | Render v1 is the sole mobile API contract; v2 and unpublished capabilities are excluded. |
| ADR-019 | Active | Persist normalized UI identity in SecureStore; never claim UI roles are backend authorization. |

Any change to an active decision requires an ADR update, specs/docs alignment, traceability, and test evidence.
