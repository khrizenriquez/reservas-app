# ADR Dependencies and Applicability

## Active mobile decisions

- ADR-011: Expo/React Native mobile architecture.
- ADR-012: Spec-driven development.
- ADR-013: Trunk-based delivery.
- ADR-016: End-to-end traceability.
- ADR-018: Render v1 is the sole mobile integration profile.
- ADR-019: SecureStore holds normalized UI identity only.

## Rejected for this cycle

The local v2/JWT/refresh baseline, Kong-specific mobile assumptions, push notifications, reports, browser CORS policy, and a web wrapper are not active.

Any decision change requires the ADR register, product spec, acceptance, traceability, and tests to be updated together.
