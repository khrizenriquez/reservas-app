# Mobile Delivery Closure

The mobile release is complete only when every HU-019 scenario is PASS or formally EXCLUDED, the Render v1 contract is verified, lint and Jest coverage are green, Android and iOS smoke evidence exists, and every AI-assisted change has human review and recorded evidence.

The mandatory functional path is login, session restore, availability, create/edit/cancel reservation, profile password, administration, users, and logs. Backend authorization remains an explicit residual risk until Render enforces it.
